== '''Overview''' ==
You cast a fish using rods. There are 21 rods that you can switch using the /rod command. The rod shop page is displayed in another page that can be accessed using the command /shop rods.

== '''Command Usage''' == 

/rod [rod]. If the rod parameter is empty the main rod page is shown. The rod parameter should have at most one space in between for it to be valid, and capitalization does not matter. If the rod parameter is a valid type of rod that you have obtained, the bot will change the type of rod to you. If the rod parameter is a valid type of rod that you haven't unlocked, the bot displays an error message stating that you have not unlocked that rod. If the rod parameter is anything else, "invalid rod" will be displayed as an error message. Note that the words "rod" can be omitted when typing the rod name.

== '''Formulas''' == 
The actual stat of rods are dependant on its base stat and your current multiplier, these buff can be viewed using /buffs 

'''Treasure Chance''': Rod Base Treasure Chance * Treasure Chance Multiplier (cap out at 100%)

'''Traeasure Quality''': Rod Base Treasure Quality * Treasure Quality Multiplier
(Note that rods extra treasure quality are added up first if the rod have them. For instance, meteor rod would be 1.3 * TQ not 1 * TQ + 0.3)

'''Fish Catch''': The fish catch follow this processes in order from up to down

CNT = V * fish catch buff
CNT += boats
CNT += BA (rounded)
CNT *= biome reducer * SR * B
CNT += boost biome multiplier * (0~4) + 1 + BB + 0~2 * FF
CNT *= (1.05 + 0.01FF + 0.01BB)

'''Fish Quality:'''
Let E_n be the current probability of getting the nth fish in the biome and Q_n be the base probability (In practice, n go from highest tier fish to lowest tier fish)

fq is the fish quality multiplier that can be seen in /buffs

E5 = Q5*fq (cap out at 1)
E_n = min[Q_n*fq, 1 - E_5 - ... - E_(n+1)]

(so for instance, E_3 = min(Q_3*fq , 1 - E_5 - E_4). The min function is used to ensure that the sum of the probabilities don't add up to above 1)
